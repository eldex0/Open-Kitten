# V10 bêta : modifications et validation

## Deuxième passe : navigation et identité visuelle

- Chat vectoriel original simplifié : aplats, silhouette géométrique, sans dégradés.
- Palette gris neutre/bleu partagée par les widgets et la page d’accueil.
- Progression de chargement de l’onglet actif et bouton arrêter/actualiser.
- Précédent/suivant désactivés lorsqu’ils ne sont pas disponibles.
- Menu d’onglet : couper/rétablir le son, copier l’adresse ; fermer les autres
  conserve les onglets épinglés. Retirer l’épingle avant de fermer un onglet épinglé.
- Ctrl+Maj+T : rouvrir ; Ctrl+Tab / Ctrl+Maj+Tab : changer d’onglet ;
  Alt+gauche/droite : historique ; F5 : actualiser ; Échap : arrêter.
- Résolution des adresses partagée entre navigation normale et privée ;
  localhost/IP utilisent HTTP par défaut, les domaines HTTPS.
- Favoris invalides filtrés à la lecture, raccourcis d’accueil dédupliqués,
  duplication des onglets différés corrigée, icônes conservées en cache.

45 tests automatisés passent après cette passe. La validation graphique réelle
et les mesures de chargement restent à effectuer, pas de garantie « zéro bug ».
Les événements de chargement et le contrôle audio suivent les API documentées
de [QWebEnginePage](https://doc.qt.io/qt-6/qwebenginepage.html).

## Paramètres

Cinq catégories : général, apparence, performances, confidentialité,
téléchargements/réseau. Validation avant écriture, annulation sans sauvegarde,
réinitialisation du formulaire avec confirmation. La langue concerne les sites,
pas une traduction de l’interface. Les proxys authentifiés ne sont pas supportés.
Les suppressions de données sont des actions immédiates confirmées séparément.

Nouveaux réglages : chargement différé des onglets restaurés, prélecture DNS,
taille maximale du cache (0 = automatique), zoom, historique, lecture automatique,
animation de lancement. Les options sans implémentation réelle, comme l’ancien
interrupteur de récupération de crash, ne sont plus présentées.

## Architecture et performances

- Persistance JSON atomique partagée : fichier temporaire puis remplacement.
- Cache mémoire des données de profil ; pas de réécriture des sessions inchangées.
- Préférences WebEngine centralisées sur le profil pour les pages futures aussi.
- Styles séparés du contrôleur de navigation.
- Filtrage de domaines par suffixes et ensemble, au lieu d’un parcours de toute
  la liste de blocage à chaque requête. Aucune désactivation des protections TLS.
- Onglets restaurés en arrière-plan chargés à leur première sélection.
  Leurs adresses sont conservées dans les sauvegardes même avant chargement.

## Bugs corrigés

- Réouverture du dernier onglet fermé, pas du premier élément de l’historique.
- Session enregistrée à la fermeture même si l’enregistrement continu est désactivé.
- Refus des valeurs de paramètres invalides ; échec d’écriture signalé sans
  appliquer une configuration non enregistrée.
- Protection des fichiers JSON existants si leur remplacement échoue.

## Validation

Exécuter `python -m unittest discover -s tests -v`.
Les tests de contrôleur emploient des vues simulées et ne valident pas Qt natif.
Le lancement graphique n’a pas pu être exécuté dans l’environnement de travail
(accès refusé au Python utilisateur). Aucun gain réseau chiffré n’est revendiqué.

Avant compilation/publication, vérifier sur Windows :

1. Ouvrir les cinq catégories, enregistrer, redémarrer et contrôler les valeurs.
2. Fermer trois onglets et les rouvrir avec Ctrl+Maj+T dans l’ordre inverse.
3. Redémarrer avec plusieurs onglets : seul le premier doit charger immédiatement.
4. Quitter avant d’activer les autres : ils doivent encore être restaurés ensuite.
5. Vérifier thèmes, zoom, favoris, navigation privée, téléchargements et vidéos.
6. Comparer les mêmes sites, connexion et cache identiques, avant/après.

Cette bêta ne garantit ni l’absence de tout bug, ni la compatibilité de toutes
les extensions ou de tous les codecs. Les crashs natifs d’extensions restent
à vérifier séparément. Une validation de diffusion publique reste nécessaire.
